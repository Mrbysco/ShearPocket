# Shear Pocket #

## About ##
Shear Pocket adds an enchantment `Pick-Pocket` that can be applied to shears. While holding the shear in your hand (or off-hand) and right-clicking a mob that's holding an item you can steal whatever they're holding in their hands.
If shearing a villager there's a chance it will reduce your reputation.
